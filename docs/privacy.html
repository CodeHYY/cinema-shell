剑透人生工作室（以下简称「我们」）是上述应用的运营者。我们重视您的个人信息保护。本政策说明应用会处理哪些信息、用于什么目的、涉及哪些第三方 SDK，以及您可以如何控制。联系邮箱：hedd8681@gmail.com。

一、先说结论

  • 应用不需要注册或登录账号，我们不收集您的姓名、手机号、身份证号等身份信息，也没有自建的用户账号体系。
  • 影视内容来自第三方公开站点，本应用不存储、不上传任何视频；我们不会读取您的相册、通讯录、短信或通话记录。
  • 在「广告版」中，集成的第三方广告 SDK 会为展示广告、归因和防作弊而处理设备标识等信息（见第三、四节）。应用启动后会初始化第三方广告 SDK。
  • 如您不希望广告 SDK 处理上述信息，可以不使用或卸载本应用，也可发送邮件至 hedd8681@gmail.com 申请处理。

六、您的权利与选择

  • 停止处理：如您不希望继续由广告 SDK 处理上述信息，可以卸载应用，也可发送邮件至 hedd8681@gmail.com 申请处理。
  • 系统层面的控制：您可随时在系统设置中重置/限制广告标识符（如 OAID、广告 ID）、关闭个性化广告、收回已授予的权限。
  • 查阅、更正、删除：我们不持有您的账号资料；本地数据（观看进度、收藏等）可在应用设置内清空或清除应用数据。对第三方 SDK 已处理的信息，您可通过其官方隐私政策中的联系方式行使权利，也可邮件联系我们协助转达。
  • 我们会在收到请求后尽快答复。

七、信息保存与安全

我们自身不在服务器上保存您的个人信息。第三方 SDK 的保存期限、安全措施见其官方政策。应用通过 HTTPS 访问更新与广告配置；部分广告 SDK 的请求可能使用明文 HTTP，这是其实现方式，我们无法改变，您可通过卸载应用来避免。
