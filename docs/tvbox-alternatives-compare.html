TVBox / 影视仓 替代方案对比：怎么选更合适

TVBox 原作者早已停止维护，现在流传的是各种分支和改版。如果你想找替代品，先要想清楚自己要什么：是想自己配站点、折腾功能，还是只想装上就看。下面客观对比几个常见选择，包括我们自己的壳。

先说明本站身份：本站是 星河影院 / 赤焰影院 等 Android 影视客户端的下载页。我们的 App 不内置片源，内容来自第三方公开站点；含第三方广告 SDK，靠广告变现，详见隐私政策。下面的教程对任何同类软件都适用，是否装我们的 App 由你决定。

FongMi / OK影视：适合愿意折腾的人

FongMi 是目前社区里更新较积极的开源 TVBox 分支，OK影视是基于它的发行版之一。它的优势是功能全：支持 Media3/ExoPlayer、mpv 播放，硬解与 FFmpeg 软解，点播、直播、DLNA、网页遥控、弹幕都有，电视版和手机版分开。代价是需要你自己找可信的配置地址并维护，地址失效是日常（排查见配置取得失败怎么办）。适合：电视盒子为主要设备、想自己挑站点、不怕调设置的用户。

影视仓等改版：适合照着教程用现成安装包的人

影视仓这类名字指的是第三方发布的 TVBox 系应用，同名安装包来源很多，版本和签名无法统一核实，选择时最好对照发布页和校验值。功能和 FongMi 同属一类，同样需要自备配置。适合：已经有稳定配置来源、习惯这套界面的用户。

星河影院 / 赤焰影院：适合只想装上就检索的人

我们的 星河影院、赤焰影院 走的是另一条路：不让用户填配置，装好打开直接检索，播放页可换线路，有弹幕和续播，不用注册。取舍也很明确：没有直播，没有自定义站点能力，片源是第三方公开站点（会变化、会失效），含第三方广告 SDK，产品页没有声明电视遥控器适配。适合：在手机上追剧、不想研究配置的用户。不适合：想自己管站点、需要看直播、要在电视上用遥控器操作的用户，这几类建议选 FongMi。

怎么选：按场景给建议

  • 电视盒子，要直播和点播，愿意维护配置：FongMi / OK影视。
  • 手机为主，想少折腾：我们的壳，或同类免配置应用。
  • 设备较老（Android 7）：看老盒子卡顿优化，再决定装哪个。
  • 在意开源可审计：FongMi。我们不开源，只提供校验值，这一点如实说明。

常见问题

TVBox 还能用吗？

原版已长期不更新，不少人转用 FongMi 等活跃分支；能否使用取决于你的配置源是否有效。

FongMi 和 OK影视是什么关系？

OK影视是基于 FongMi 的发行版之一，核心逻辑一致，界面和附加功能略有差异。

你们的 App 和 TVBox 是同类吗？

不是。TVBox 类是「空壳 + 你填配置」，我们的壳免配置，片源路由由我们维护，能力更窄，换来的是上手简单。

有广告吗？

有。我们集成了第三方广告 SDK，靠广告变现，处理哪些信息见隐私政策。
