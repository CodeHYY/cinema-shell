映屿是什么

映屿是原生影视客户端：首页轮播与热播片单、电视剧/电影/短剧/动漫/综艺/纪录片分类与筛选、榜单、搜索与搜索历史；详情页有简介、选集、系列与推荐；播放器自绘播控，支持倍速、全屏、多线路自动换源、弹幕、续播和自动连播。观看进度与收藏仅保存在本机。影视内容来自第三方公开站点，本应用不存储、不上传任何视频。

  • 详情页选集、系列与推荐
  • 自绘播控：倍速、全屏、多线路自动换源、弹幕、续播、自动连播
  • 观看进度与收藏仅保存在本机

常见问题

为什么要「允许未知来源」？这个包安全吗？

这些应用没有上架应用商店，需要从网站直接安装，系统因此要求你手动允许。我们只在本站和 GitHub 仓库发布安装包，并公布每个包的 SHA-256 供核对；请不要从其他来源下载。应用请求的权限与第三方 SDK 都列在隐私政策里。

需要注册或登录吗？

不需要。应用没有账号体系，观看进度、收藏、搜索历史只保存在你的设备上。

有广告吗？涉及哪些信息？

星河影院 1.3.3、赤焰影院 1.3.3、映屿 1.4.0、追光 1.7.1 集成了第三方广告 SDK，靠广告变现，不是无广告应用。应用启动后会初始化广告 SDK，处理哪些信息、涉及哪些权限见隐私政策；不想被处理可卸载应用或邮件申请。

影视内容从哪里来？

来自第三方公开站点或采集站的公开接口，应用本身不存储、不上传任何视频。第三方内容可能随时变更、失效或下线。

提示无法播放 / 一直转圈怎么办？

先在播放页切换线路；仍不行可能是该片源暂时失效，稍后再试或换一部。确认网络正常后仍有问题，请发邮件或在 GitHub Issues 反馈，注明产品、版本、片名和手机型号。
