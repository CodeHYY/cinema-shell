小米电视 / 红米电视 怎么安装第三方 APK？

小米电视和红米电视都跑 Android 内核的系统，可以安装应用商店之外的 APK。常用的有三条路：U 盘最稳，手机推送最省事，adb 最灵活。先做第一步的权限，三种方法都需要。

先说明本站身份：本站是 星河影院 / 赤焰影院 等 Android 影视客户端的下载页。我们的 App 不内置片源，内容来自第三方公开站点；含第三方广告 SDK，靠广告变现，详见隐私政策。下面的教程对任何同类软件都适用，是否装我们的 App 由你决定。

开始之前：下载对的 APK

电视用的应用要下电视版（TV 版）APK，用遥控器操作才方便；手机版 APK 能装上，但界面按钮小、遥控器很难点。另外确认 APK 的最低系统要求，不低于你电视的 Android 版本，否则会提示「解析包出错」。

第一步（都要做）：允许安装未知来源应用

不同年份的系统菜单文案不一样，常见路径有：

  • 设置 → 账号与安全 → 允许安装未知来源应用（老一些的系统叫「未知来源」）；
  • 较新的系统：设置 → 账号与隐私（或「安全和隐私」）→ 安装未知来源应用。

把开关打开；有的版本需要分别给「文件管理」「小米电视助手」等具体应用放行。找不到时，在设置里逐级点开「账号与安全」「隐私」相关页面，没有统一入口名。

方法一：U 盘安装（兼容性最好）

  1. 电脑上把 APK 复制到 U 盘根目录，文件名改成简短英文，如 app.apk；U 盘建议 FAT32 格式（老电视对 exFAT、NTFS 支持不稳定）。
  2. U 盘插到电视 USB 口。
  3. 打开电视自带的「文件管理」（有的叫「文件浏览」），进入 U 盘，选中 APK，按遥控器确认键，选「安装」。
  4. 自带文件管理找不到 APK，或没有安装入口，可以先装一个第三方文件管理器再试。

方法二：手机推送（小米电视助手）

手机装「小米电视助手」，手机和电视连同一个 Wi-Fi，在助手里找到本地安装（或应用管理）里的安装 APK 功能，选手机里的 APK 文件发送到电视，电视端弹出确认后点确定。不同版本的助手菜单名略有差异，文件放在手机公共目录（如 Download）里更容易被识别，放在微信/QQ 目录里有时扫不到。

方法三：adb 命令安装（进阶）

  1. 打开开发者模式：设置 → 关于 → 找到「产品型号」，用遥控器确认键连续点击多次，出现提示即已开启。
  2. 回到 设置 → 账号与安全，会多出ADB 调试开关，打开它。（这个开关在电视重启后常会自动关闭，要重新打开。）
  3. 在 设置 → 网络 里查看电视的 IP 地址，例如 192.168.1.20。
  4. 电脑已装好 adb，和电视在同一局域网，执行：
    adb connect 192.168.1.20:5555
    adb install -r app.apk
  5. 第一次连接电视上会弹授权框，选「允许」。显示 Success 即安装完成。

装好了但桌面找不到图标？

手机版 APK 通常没有电视桌面的启动入口，装成功了也看不到图标。可以到 设置 → 应用 里找到它并打开，或者用第三方桌面 / 应用管理器启动；adb 用户可以执行 adb shell monkey -p 包名 1 启动。

常见报错

  • 解析包出错：文件没下完整，或 APK 要求的 Android 版本高于电视；重新下载并核对 SHA-256（我们的页面都公布了校验值）。
  • 签名冲突 / 与已安装应用冲突：电视上已有同包名不同签名的版本，先卸载旧版再装。
  • 存储空间不足：电视存储常常只有 8 GB，清理不用的应用。
  • adb 显示 unauthorized：电视上的授权框没点允许。

关于我们的 App 与电视

星河影院、赤焰影院 的安装包约 12 MB，要求 Android 7.0 及以上，主要按手机使用设计，产品页没有声明针对电视遥控器做过适配，所以放到电视上用，请自己实测。手机上的安装步骤（含小米、华为、OPPO、vivo 的放行菜单）写在安装指南里。我们的 App 不带片源，含第三方广告 SDK，详见隐私政策。装好后需要配置点播源的教程见这里。

常见问题

小米电视没有「未知来源」选项怎么办？

先到 设置 → 账号与安全 / 账号与隐私 里找；仍没有就用 adb 方法安装，或把 APK 放进 U 盘用文件管理打开，系统一般会在安装时弹出放行提示。

红米电视和小米电视步骤一样吗？

基本一致，都是同一套系统，只是菜单文案随系统版本略有不同。

安装第三方应用会影响保修吗？

安装 APK 不涉及修改系统底层，但具体政策以小米官方客服为准，我们不替官方作保证。

adb 连不上怎么办？

确认电脑与电视在同一网段、电视的 ADB 调试已打开（重启后会关）、没有防火墙拦截 5555 端口。
