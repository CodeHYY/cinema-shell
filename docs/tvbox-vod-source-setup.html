电视盒子点播源怎么配置？配置地址在哪填

装好 TVBox、影视仓、OK影视这类软件后首页是空的，这是正常的：它们不带片源，要自己在设置里填一个「配置地址」（也叫点播源、接口、仓库），软件才有内容。本文说明填在哪、怎么填、怎么确认成功。

先说明本站身份：本站是 星河影院 / 赤焰影院 等 Android 影视客户端的下载页。我们的 App 不内置片源，内容来自第三方公开站点；含第三方广告 SDK，靠广告变现，详见隐私政策。下面的教程对任何同类软件都适用，是否装我们的 App 由你决定。

配置地址、点播源、接口、仓库是什么关系

叫法不同，指的是同一类东西：一个指向 JSON 配置文件的网址。文件里写着有哪些站点、分类怎么取、线路怎么解析。常见分两种：

  • 单仓（单线路）：一个地址对应一套站点，加载快，出问题好排查；
  • 多仓（仓库）：一个地址里列了好几个单仓，进软件后可以切换，选择多，但加载更慢、更容易有失效项。

直播同理，有单独的「直播地址」，填法和点播一样。

配置地址填在哪

不同版本菜单不同，但逻辑相同：

  • OK影视 / FongMi 系：首页右上角设置（齿轮）→ 配置地址（或「点播」）→ 弹出输入框，填入地址，点确定，返回首页等待下载。「直播」「壁纸」的地址填法一样；输入框旁的小房子图标可以查看历史记录。
  • 影视仓：设置 → 配置地址 / 仓库，手机版有的在首页右上角「+」里添加。
  • TVBox 原版及其他分支：设置 → 数据源 / 接口地址。

找不到时，设置页里把每一项点开看，带「配置」「接口」「订阅」「仓库」字样的就是。

怎么输入：三种方式

  1. 遥控器直接输入：慢且容易错，适合短地址。
  2. 手机推送（推荐）：电视和手机连同一 Wi-Fi，电视端打开推送入口会显示二维码或网址（FongMi 系常见是「电视 IP + 端口」的形式，以界面显示为准），手机扫码或访问，在页面里粘贴地址并推送，电视端点确定。
  3. 本地文件：把配置文件放在 U 盘或设备存储里，填本地路径（FongMi 系支持 file:// 形式，具体写法以所用版本的说明为准）。适合没有稳定网络访问源站的情况。

怎么确认配置成功

点确定后返回首页，等待片刻，顶部会出现分类标签和推荐内容；在设置里还能切换站点。如果弹出「配置取得失败」之类提示，按这篇排查步骤处理。

配置地址从哪来、要注意什么

配置由第三方社区维护，本站不提供、也不推荐具体地址。使用前请知道：

  • 地址会随维护者变动而失效，需要自己更新；
  • 配置里可以带爬虫代码（jar、js、py），会在你的设备上执行，只用你信得过的来源，不要在装有重要账号的手机上随便试；
  • 片源版权属于各自权利人，是否合法使用请自行判断。

填完没反应，常见几种情况

  • 返回首页后仍空白：多等十几秒；仍不行就是地址取不到，换地址或换网络。
  • 提示格式错误：地址不是配置文件的直链，是某个网页，换成直链。
  • 能进首页但只有个别站点可用：正常现象，换站点或换更勤维护的配置。
  • 换了设备就不行：多半是 DNS 或时间问题。

我们的 App 要不要填配置

星河影院、赤焰影院 不需要这一步：首页直接检索，片源路由由我们自己维护，产品页没有提供导入自定义配置的功能；内容来自第三方公开站点，换线路由播放页完成。它不带片源，含第三方广告 SDK（详见隐私政策），不需要注册。想自由配置站点的用户，更适合 FongMi / OK影视 这类软件，对比见TVBox 影视仓替代对比。

常见问题

配置地址和直播地址能填同一个吗？

有些配置文件同时带点播和直播，填了点播会自动带出直播；没有带的话直播要另外填。

单仓和多仓选哪个？

追求稳定先用单仓；想多备几个站点再用多仓，并接受加载慢一些。

手机上也能用这种软件吗？

能，FongMi 系有手机版，配置方法相同。

这些软件自带片源吗？

不带。没有配置时首页就是空的，这是正常现象。
